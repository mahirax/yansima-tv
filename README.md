# YANSIMA TV Android Projesi

Dört ön tanımlı kanal:
- YANSIMA SİNEMA TV
- YANSIMA MÜZİK TV
- YANSIMA DANCE TV
- YANSIMA SLOW TV

Android Studio'da projeyi açıp Gradle senkronizasyonunu tamamlayın ve Build > Build APK(s) ile APK üretin.

Not: Bu arşiv Android kaynak projesidir; derlenmiş APK değildir. Yayınların erişilebilirliği ve sağlayıcı koşulları cihazda test edilmelidir. İlk üç yayın HTTP kullandığından manifestte cleartext izni açık tutulmuştur. Yalnızca kullanma izniniz olan yayınları kullanın.
